# References

- [WebAssembly Core Specification](https://webassembly.github.io/spec/core/) — Defines the executable module format and core semantics used by Wisp emulator plugins.
- [Web Cryptography API](https://www.w3.org/TR/WebCryptoAPI/) — Defines browser cryptographic primitives used by WispOS to verify SHA-256 artifact hashes and ECDSA P-256 signatures.
- [Gamepad specification](https://w3c.github.io/gamepad/) — Defines the browser controller-input surface owned by the Games frontend rather than individual console cores.
- [Web Audio API](https://www.w3.org/TR/webaudio-1.1/) — Defines browser audio output used by Games for emulator PCM presentation.
- [GitHub repository contents](https://docs.github.com/en/rest/repos/contents) — Documents the GitHub transport used for signed catalog and package bytes. GitHub is not a WispOS trust root.
